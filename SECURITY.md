# Security policy

## Reporting a vulnerability

Please report security problems privately: on this repository's **Security** tab, click **Report a vulnerability**. Please don't open a public issue for them, and don't include real secrets in a report: a fake value that shows the problem is enough.

## Scope

paste-redact is a safety net, not a guarantee (see "Limitations" in the README). A sensitive value that no pattern recognizes and that isn't in your terms file is not a vulnerability, but a pattern that should match and doesn't is worth reporting. Only the latest version on `main` is supported.
